# 产品与器械跨模块论证清单 v0.1

> 身份：当前有效的跨模块候选清单；用于收集产品、植入物与器械在不同业务模块之间出现、但尚未由任何一个模块拥有并确认的论证问题。不是产品目录、库存规则、手术植入规则、手术通知规则、页面方案、技术规格或验收结论。
>
> 建立日期：2026-09-04

## 1. 使用边界

- 只收录来自已沉淀业务场景、且可能影响两个以上模块的问题；
- 每条必须区分已知事实、候选思路和待论证内容；
- 清单中的任何条目均不得作为当前模块的产品选择、来源判定、库存扣减、接收、包装拆分、页面或技术实现依据；
- 结论须先由拥有事实的模块写入正式资料，再在本清单回填正式去向或不采用理由；
- 本清单不替代[跨模块遗产索引](./跨模块遗产索引-v0.4.md)，已确认的共同事实仍由遗产索引定位。

## 2. 当前条目

### P-I01｜候选收集｜拆盒与多层包装的实物追溯粒度

| 字段 | 内容 |
|---|---|
| 触发场景 | 手术植入术后凭证可能只粘贴外盒标签；例如一盒同规格钉子只有外盒带胶贴，拆出的单枚没有独立标签。现实产品还可能存在外盒、内袋、单枚或套件等多层包装。 |
| 已知事实 | 手术植入以术后医院使用登记单或同等凭证的胶贴取得实际使用的产品、批号／可追溯身份和数量；实物来源目前按“产品＋批号／可追溯身份（如有）＋数量”回查。手术植入当前规则已明确：拆盒后不能按单件追溯、同一实物可对应多个来源的识别与分摊细则尚未确认。 |
| 候选思路 | 后续可论证“带身份的最小可识别包装层”与“实际使用单位”是否应分开：若外盒足以证明同规格、同批号内件，则实际使用数量可引用该包装身份；若外盒不足以证明内部产品、规格或批号，则不得据外盒自动推导内件的已核实身份或来源。此为待论证思路，不是当前规则。 |
| 待论证内容 | 最小可追溯包装层如何识别；同规格整盒、异规格组合盒、外盒与内袋信息不一致或粒度不同等情形的证据边界；包装包含数量与多次实际使用之间的守恒；来源分摊、剩余实物、拆盒后再交接及无法证明内部构成时的异常结果。 |
| 可能影响 | 手术植入的明细来源核验与正式结果；库存管理的实物关系、常备物资、接收与后续剩余责任；手术通知的候选实物数量与结余责任。不会因此自动增加新的通知状态、库存动作、后台页面或扫码要求。 |
| 未来归属与退出条件 | 由库存管理的实物关系与责任阶段牵头，手术植入、手术通知按各自已确认接口参与。形成结论后，先写入拥有事实的正式规则／接口资料，再回填本条及必要的跨模块遗产索引。 |

## 3. 当前恢复点

P-I01 已作为非阻塞桩子隔离。手术植入当前继续推进“来源待核实”这一正式结果的定义、反向撤销与混合来源验证；不得为解决 P-I01 提前设计包装字段、扫码流程、库存扣减或后台能力。
