# 公司库存业务接口登记

> 状态：当前有效。  
> 身份：T4 的跨任务业务边界入口；不定义技术协议或端能力。

| 相邻任务／模块 | 当前可使用的边界 | 明确不包含 |
|---|---|---|
| T2 APP－库存管理 | T2 是业务员移动端模块；其现有资料不能自动成为 T4 的公司库存事实。 | T2 的页面、操作、库存规则与候选输入。 |
| T3 APP－手术通知 | 手术通知形成需求并承接公司库存形成的供货承诺；已接收实物形成来源订单在手待结余责任；常备不足的需求缺口由通知承接。 | 通知内部状态机、要货流程、页面与公司履约方式；具体实物绑定、来源选择和履约动作。 |
| T1 APP－手术植入 | 来源追溯粒度为产品、批号／可追溯身份（如有）与数量；手术植入形成其正式结果，公司库存读取已正式成立的结果以改变自身实物关系，但不改写植入结果。 | 植入内部流程、库存扣减／恢复和技术字段。 |
| 库存 Web 后台 | 尚无已确认接口；不因 T4 启动而自动建立。 | 页面、岗位、审批、看板、自动化、技术接口。 |

## 待确认接口

T4 稳定后再判断哪些公司库存正式结果应由 T1、T2、T3 或未来端承接；当前不得预设回写、字段、调用或责任分配。
