# Skill 与项目资料防污染规则

## 1. 文件身份

| 项目 | 内容 |
| --- | --- |
| 文件性质 | `orthoflow-erp` 项目级治理规则 |
| 当前状态 | 当前有效 |
| 目标 | 防止通用 Skill、项目规则、模块业务事实和原型验证资料互相覆盖或反向推导 |
| 不承载 | 手术通知、手术植入、库存或其他模块的业务规则、页面状态和接口事实 |

本文件是项目规则，不是第二个可执行 Skill。通用推进方法仍以独立仓库发布的 `advance-business-module` 为唯一来源；项目业务事实仍以各模块当前有效资料池为准。

## 2. 四层权威与禁止事项

| 层级 | 唯一权威位置 | 可以承载 | 不得承载或推导 |
| --- | --- | --- | --- |
| 通用推进方法 | 独立 `advance-business-module` 仓库及项目锁定快照 | 资料接管、三态判断、宏观优先、提问、闸门、版本和发布方法 | 本项目页面、状态、角色、接口、低保真验收细节 |
| 项目治理规则 | 根 `AGENTS.md`、本目录 `docs/governance/` 和项目进度规范 | 项目范围、资料身份、阶段顺序、驾驶舱、组间闸门、原型身份和跨层同步顺序 | 任一模块的未确认业务取舍 |
| 模块业务事实 | 对应模块总池、规则池、接口池、设计池和验收池 | 对象、角色、责任、状态、页面、正式结果、接口和桩子 | 其他模块内部流程；Skill 通用方法 |
| 原型与设计验证 | `prototypes/`、设计探索稿及其 README | 页面承载假设、入口动作演示、状态占位和结构验证证据 | 正式业务事实、正式权限、正式库存、正式接口和未确认状态 |

发生冲突时，按“当前有效模块资料 → 项目治理规则 → Skill 方法 → 原型验证资料”的事实优先级处理；Skill 只能规定如何处理冲突，不能替模块资料裁决业务事实。

## 3. 低保真与原型的条件性边界

1. 低保真不是通用 Skill 的全局默认阶段；是否进入低保真由项目阶段和模块准入条件决定。
2. 项目低保真阶段可以要求真实入口、本人动作、结果回写、异常、取消和失败恢复等验证，但这些是项目级阶段要求，不写回通用 Skill。
3. 原型中的总览页、组总览和单页详情用于设计审阅时，必须显式标记其身份；它们不因为出现在原型中就自动成为正式 APP 页面。
4. 全部页面总览和组总览是审阅导航时，正式页面数量、页面职责和业务入口仍以当前页面清单与页面流程为准。
5. 原型发现的缺口只能回写到所属规则、接口、页面流程或桩子资料；不得在原型中静默补成已确认规则。

## 4. 模块与跨模块边界

1. 一个模块只维护自己拥有事实和正式动作的对象、状态、任务和结果。
2. 跨模块只传递已确认的输入、输出、状态、任务、返回上下文或正式结果；不复制来源模块的完整页面和内部操作。
3. 任务中心、订单中心或全局总览可以提供入口和摘要，但不代替来源模块执行正式动作，不建立第二套事实或任务池。
4. 相邻模块未启动、接口未确认或内部规则未形成时，只登记桩子和恢复条件，不从页面编号、原型、聊天或行业惯例补全。

## 5. 变更归属与同步顺序

### 通用 Skill 变更

1. 先在独立 Skill 仓库完成归属判别、修改、行为案例、快照校验、版本、标签和 Release。
2. 远端 Release 验证通过后，才同步项目内快照和 `Skill版本锁定.md`。
3. 项目副本不得自行增加通用语义规则或独立递增版本。

### 项目治理变更

1. 只修改根 `AGENTS.md`、本目录治理文件或适用进度规范。
2. 不把项目专属页面、低保真或模块规则复制到 Skill。
3. 影响阶段、边界、页面身份、硬闸门或恢复点时，更新适用进度记录并显式报告影响。

### 模块业务变更

1. 只写入所属模块的规则、接口、设计、验收或历史资料池。
2. 跨模块影响只更新已经确认的接口摘要，不复制另一模块的内部流程。
3. 未确认内容登记为桩子，并记录所属对象、归属阶段或模块以及是否阻塞当前任务。

## 6. 防污染检查

在组间切换、全流程验收、低保真准入或 Skill 版本同步前，至少检查：

- 当前结论是否能追溯到正确层级的正式文件；
- 原型是否把占位状态、权限、库存、审核或后台动作画成既定事实；
- 项目治理是否把模块业务规则写成全局规则；
- 模块资料是否复制了相邻模块的内部页面或未经确认的接口；
- 当前 Skill 路径、版本、快照、锁定提交和远端 Release 是否一致；
- 旧名称、旧状态、旧页面或聊天独有结论是否残留在当前有效资料中。

发现污染或冲突时，冻结下游设计和提问，回到唯一权威层修复；不得用原型、流程图、进度记录或下一轮对话静默覆盖事实来源。

## 7. 当前项目的最小判断口径

- “Skill 怎么推进”看独立 Skill 和项目锁定快照；
- “项目如何组织资料和阶段”看 `AGENTS.md` 与项目治理资料；
- “模块具体做什么”看模块当前有效资料池；
- “页面是否好用、结构是否可执行”看项目低保真阶段的原型验证，但原型不能反向成为业务规则；
- “跨模块如何衔接”看已确认接口登记，不看聊天记忆或相邻模块的完整流程。
