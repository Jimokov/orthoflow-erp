# 侧边对话承接索引

> 状态：当前有效的项目级承接定位索引；不保存业务事实，不替代任务与对话承接矩阵、模块资料或正式模块启动资料。
>
> 使用协议：[侧边对话承接与退出协议](../governance/侧边对话承接与退出协议-v0.1.md)。

## 使用规则

- 每个仍在讨论或已冻结待承接的侧边讨论只登记一条索引；子承载在同一条目中列出，不另建活动任务；
- 新对话任务脉冲只读取与其绑定任务或用户本条指定任务相关的条目；
- “讨论中”条目定位实时承载；“已冻结待承接”条目定位独立继承包；
- 条目中的用户输入、推导、探索和桩子均须回到承载文件审查，不能由本索引升级为事实；
- 用户发起交接后，更新状态和冻结包位置；主对话完成逐项处置后记录正式去向或不采用理由。
