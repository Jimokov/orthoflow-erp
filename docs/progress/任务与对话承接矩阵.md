# 任务与对话承接矩阵

> 状态：当前有效的任务关系索引
> 建立日期：2026-08-24
> 作用：管理模块任务如何承接、旧对话如何一次性迁移及下一任务的进入条件；不保存业务事实。

## 使用规则

- 每个任务只标注一种类型：全新承接、历史迁移或正常续接。
- 业务事实只存在于模块总池、规则池、接口池、设计池、代码池或验收池；本矩阵只链接这些正式资料。
- 历史迁移中的候选不是事实，必须经用户确认并写入正式资料后，才可被后续任务继承。
- 旧对话完成迁移后退出业务推进职责；新任务不得再将其历史当作背景补充。
