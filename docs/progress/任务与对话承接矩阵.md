# 任务与对话承接矩阵

> 状态：当前有效的任务关系索引
> 建立日期：2026-08-24
> 作用：定位当前活动任务及其正式入口、状态、恢复点和转换条件；不保存业务事实。

## 使用边界

- 只登记当前活动任务 `Tn`、绑定对话、正式入口、状态、恢复点和转换条件。
- 任务绑定、切换与冲突治理遵循[跨对话任务编排与增量收工治理方案](../governance/跨对话任务编排与增量收工治理方案-v0.3.md)；业务事实回到所属模块正式资料。
- 已完成迁移、已退出对话和历史来源不作为活动任务；需要追溯时从其正式记录定位。
