# 项目对话编号登记

> 状态：当前有效的项目对话窗口索引；不保存业务事实，不替代日报、任务与对话承接矩阵或模块资料。

## 使用规则

- 新项目对话窗口在首次回复前读取本文件，取“下一个编号”作为窗口编号，并把该编号、开始日期和主题登记为一行；
- 同一窗口内的每条助手回复均使用同一编号；跨日续接仅更新日期并加注“续接”，不重新取号；
- 已结束窗口不复用编号。登记只用于可读定位，不替代 Codex 的系统线程 ID；
- 新窗口登记完成后，将“下一个编号”加一。无法确认编号时，先停止业务结论形成并说明编号登记缺口。
