## 使用规则

- 每个自然日独立编号：当天第一个项目对话窗口为 `01`，后续新窗口依次加一；新日期不继承前一日编号；
- 新窗口在首次回复前读取本文件，取当日“下一个编号”，并登记日期、编号和主题；同一窗口在当天的每条助手回复使用同一编号；
- 同一 Codex 窗口跨日续接时，在新日期重新登记并分配该日序号；
- 登记只用于可读定位，不替代 Codex 的系统线程 ID。无法确认当日编号时，先停止业务结论形成并说明编号登记缺口。
