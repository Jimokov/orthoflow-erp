# 手术植入模块总池

> 建池日期：2026-08-24  
> 当前阶段：I01 错误当前权重与既有低保真准入已经撤销并通过用户验收；既有业务成果完整保留，业务与设计推进暂停，下一项手术植入治理切片尚未确认。
> 当前作用：这是接管“手术植入模块”的唯一入口；本模块运行于业务员移动端。
>
> 2026-09-03 术语对齐：当前有效资料与探索载体统一使用“业务员侧常备物资”描述原非通知来源；历史接管包、旧计划与历史索引保留原称呼，仅用于追溯。

## 1. 模块身份与边界

- 所属端：业务员移动端 APP；
- 已确认定位：手术植入是现实手术完成后，对本次实际销售事实的据实登记；
- 不承担术前要货、备货、产品质量检查、手术现场决策、采购、调拨、入库或 Web 后台内部作业；
- 与手术通知有关的任何事实，只继承 `APP-手术通知` 当前有效资料及后续确认的接口；本模块不得用历史材料改写手术通知；
- 库存管理功能模块已进入启动前资料审校，但库存内部操作、Web 手术植入后台、视觉和代码均未启动；I01—I05 的低保真探索节点不等于正式页面清单或设计验收。
