## 1. 已确认规则

| 编号 | 规则 | 依赖／作用 |
|---|---|---|
| R-01 | [模块定位与边界](./01-手术植入APP模块定位与边界-v0.1.md) | 手术完成后的实际销售事实登记；限定模块边界。 |
| R-02 | [记录粒度与跨模块归属](./02-手术植入APP记录粒度与跨模块归属-v0.1.md) | 一名业务员＋一位患者＋一次实际手术事件。 |
| R-03 | [人工基础信息边界](./03-手术植入APP人工基础信息边界-v0.1.md) | 医院、科室、术者、患者姓名和住院号的采集边界。 |
| R-04 | [销售形态确定规则](./04-手术植入APP销售形态确定规则-v0.1.md) | 有效销售关系决定实物销售或数据销售。 |
| R-05 | [销售形态历史快照](./05-手术植入APP销售形态历史快照-v0.1.md) | 正式记录固化销售形态。 |
| R-06 | [实物销售来源与通知回写](./06-手术植入APP实物销售来源与通知回写-v0.1.md) | 实物销售按来源分配，并向手术通知回写。 |
| R-07—R-08 | [入口归一与通知上下文](./07-手术植入APP入口归一与通知上下文-v0.1.md) | 两类入口共享同一记录；通知来源关联与回写按 R-06 进行。 |
| R-09—R-10 | [扫码与手动添加](./08-手术植入APP扫码与手动添加-v0.1.md) | 两种录入方式形成同一实际销售明细与追溯链路。 |
| 业务语义-01 | [实际手术动作与销售结果关系](./09-实际手术动作与销售结果关系-v0.1.md) | 动作事实与销售结果分离；仅实际销售明细进入正式结果与通知来源回写。 |
| 业务语义-02 | [未正式形成记录失败恢复](./10-未正式形成记录失败恢复-v0.1.md) | 可补齐重提；明确放弃或超期后退出；未正式阶段不回写，重新通过校验后才形成正式结果。 |
