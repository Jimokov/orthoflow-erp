# 手术植入完整流程复走核查记录 v0.1

> 状态：当前有效的流程复走记录；不新增业务规则、页面、技术实现或相邻模块事实。  
> 核查日期：2026-09-04。  
> 范围：复走两个入口、实物销售记录形成、未正式恢复、正式结果、通知回写及生命周期；数据销售只核对已有边界，不在本记录中补造其流程。

## 1. 当前复走主线

```text
现实手术完成
→ G01 独立进入，或 O01／G03 手术情况确认进入
→ 建立同一种实际手术事件与植入销售记录
→ 销售形态由有效销售关系自动确定并在正式结果固化
→ 实物销售以胶贴或同等凭证形成实际销售明细
→ 系统按实物上游链确定来源，必要时形成待核实关联
→ 凭证关联、提交与自动校验
→ 正式结果，或未正式形成后的补齐／退出
→ 通知按有效结果重算责任与结余
→ 来源核实校正，或取消／失效／销错冲正的可追溯反向处理
```

## 2. 已通过的连续性核对

| 环节 | 已核对事实 | 结论 |
|---|---|---|
| 入口 | G01 与 O01／G03 进入同一种记录；通知入口只提供上下文，不能预置实际使用结果。 | 连续。 |
| 实际使用明细 | 胶贴或同等凭证是事实锚；扫码、拍照识别、补拍与手动补录形成同一种明细；手动补录不面对公司总目录。 | 连续。 |
| 实物来源 | 系统按原始来路与最近有效交接确定来源；业务员不手动选择来源。正常通知来源、业务员侧常备物资与来源待核实结果按明细分开。 | 连续。 |
| 正式形成前 | 凭证关联后提交校验；不完整或校验异常保持未正式形成，可补齐重提或退出，均不回写通知。 | 连续。 |
| 正式结果与通知 | 正常通知来源正向回写；带通知上下文的来源待核实使用形成非结清关联；无通知上下文的不触碰通知。 | 连续。 |
| 后续变化 | 来源核实只校正同一有效记录的责任；取消、失效和销错冲正撤销原记录产生的全部通知侧结果，正确结果另行形成。 | 连续；N-X03 已由手术通知正式收口。 |
