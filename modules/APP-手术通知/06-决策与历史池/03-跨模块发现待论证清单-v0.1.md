# 手术通知跨模块发现待论证清单 v0.1

> 身份：当前有效的通知模块论证入口清单；不新增或修改手术通知规则、接口、页面、任务或状态。
>
> 用途：其他模块发现手术通知可能存在未论证边界时，先在此登记，再由手术通知对话自行论证、确认或拒绝。

## 1. 使用规则

- 只登记可能影响手术通知自身对象、责任、结果、任务、接口、术语或页面承载的问题；
- 每条发现必须引用发现方的当前资料和手术通知已知资料，不能以旧聊天或候选想法替代依据；
- “可能影响”不是手术通知事实，也不授权发现方修改通知资料；
- 手术通知对话处理后，先更新通知拥有的正式事实资料，再把本条标为已确认并链接去向、已拒绝或继续保留桩子；
- 只有已确认的交叉事实或稳定桩子才同步至项目级跨模块遗产索引。

## 2. 条目模板

| 字段 | 必填内容 |
|---|---|
| 编号与状态 | `N-Xxx`；待手术通知论证／已确认并已转入／已拒绝／保留桩子 |
| 发现来源 | 发现模块、触发场景和当前资料位置 |
| 已知通知事实 | 当前通知资料已经覆盖的内容及来源 |
| 待论证问题 | 一个明确的通知模块问题，不预写答案 |
| 可能影响 | 可能涉及的通知资料或相邻模块结果 |
| 处理与退出 | 后续由谁论证；确认后写入的正式资料位置或拒绝理由 |

## 3. 当前条目

暂无。手术植入来源锚定讨论当前暂停；以后只有发现其确实触及手术通知尚未定义的责任、任务、回写、术语或承载时，才登记新条目。
