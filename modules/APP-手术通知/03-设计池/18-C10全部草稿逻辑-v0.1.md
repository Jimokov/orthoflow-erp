# C10 全部草稿逻辑 v0.1

> 状态：单页逻辑已确认
> 更新日期：2026-08-18
> 范围：只定义C10单页逻辑；不制作低保真，不管理模板候选，不展示正式订单列表或详情

## 1. 页面身份

C10是全部未提交订单草稿的查找、继续和按业务身份退出页面。它是C00的下级载体，不是新的创建入口，不承担正式订单列表／详情、待我处理、模板资产或后台管理能力；撤回修改稿上的正式取消只是保护既有订单身份的退出动作，不把C10扩展成订单页。

C00只展示最近一张可继续草稿；C10承载其余全部订单草稿，并与C00、来源O01引用同一草稿对象。

## 2. 已确认的列表组织

C10使用一个列表，只按当前能否继续分成两层，不按新建、模板、复制、补充和撤回建立五个标签页：

1. **可继续**：页面主体，按内容最后一次成功保存在本机的编辑时间倒序；
2. **无法继续（N）**：位于列表底部，通常收起，不与可继续草稿交错。

从C00“有草稿无法继续，查看全部草稿”进入时，C10自动展开并定位“无法继续”；其他入口保持可继续草稿优先。

公司端同步时间不改变草稿排序。尚未同步但已在本机持久保存的草稿仍进入可继续列表，并低强调显示“待同步”。

## 3. 草稿卡片

每张卡片只显示识别和继续所需的信息：

- 优先使用医院、术者和手术日期形成主识别信息；三项均缺失时显示“新建需求（信息未完善）”；
- 来源使用短标签：新建需求、来自模板、复制需求、补充订单、修改订单；
- 只有补充订单和修改订单显示关联订单号，其他草稿不预留空行；
- 显示最后编辑时间；尚未同步时附加“待同步”；
- 不显示产品／器械清单、完成百分比、正式订单状态、履约进度或待办。

来源只帮助识别，不作为页面分类。

## 4. 可继续与无法继续

### 4.1 可继续草稿

- 整卡点击恢复上次有效编辑页面与位置，不另设重复的“继续编辑”按钮；
- 普通删除等低频动作进入卡片“更多”，不与继续操作争夺主视觉；
- 删除前必须用当前草稿识别信息进行明确确认，删除后留在C10并保持原列表位置。

普通删除只适用于从未正式提交的普通订单草稿和尚未正式提交的补充需求草稿。撤回修改稿按第4.3节处理，不显示普通“删除草稿”。

### 4.2 无法继续草稿

- 不能强行进入已经失效的旧编辑流程；
- 展开后显示一条具体原因，例如来源订单当前状态不再允许补充；
- 有来源订单时可以查看来源O01；
- 可以清理没有正式订单身份的普通草稿或尚未提交的补充草稿；删除补充草稿时，C00、C10和来源O01对同一草稿的引用同时消失；
- 不自动转成普通新订单，不把失效草稿算作待办，也不由系统静默删除。

无法继续只描述当前不能沿旧编辑上下文继续，不自动赋予任何草稿删除资格。撤回修改稿即使失效，也必须按既有正式业务身份决定下一步。

### 4.3 撤回修改稿

待受理原单或补充单撤回后，修改稿仍保留原订单／补充单编号、业务身份和首次提交历史，因此与从未提交的普通草稿分开处理：

- 撤回原单修改稿提供“继续修改”和“取消订单”，不提供普通“删除草稿”；
- 撤回补充单修改稿提供“继续修改”和“取消本次补充”，不提供普通“删除草稿”；
- 取消是需要联网并按当前订单事实与权限重新校验的正式动作，不是清理本机草稿；
- 撤回原单仍满足“原单未受理、不存在已受理单据且没有实物流”时，取消成功后整张订单正式进入已取消，保留订单编号、首次提交、撤回和取消历史，并进入对应O01与历史订单；
- 撤回补充单取消成功后，只终止该张接续订单并保留其编号与历史，不影响已受理原单、其他接续订单或整个手术需求组；结果回写来源O01对应接续订单与O04；
- 如果公司受理、权限或订单事实已经先变化，旧动作不得执行；页面保留修改稿、说明最新原因，并按最新事实返回来源订单或允许的处理入口。

## 5. 搜索与空状态

搜索只覆盖医院、术者、手术日期和关联订单号，不增加来源筛选、状态筛选、高级筛选或批量管理。

删除最后一张草稿后显示“暂无草稿”，只提供返回C00；C10不重新加入“新建手术通知”。

## 6. 明确不包含

- 不按来源建立多标签页；
- 不提供批量删除；
- 不展示正式订单状态、履约或任务；
- 不管理模板候选、共享模板或已下载模板；
- 不提供新建订单入口；
- 不允许用删除草稿代替正式取消订单。

## 7. 单页收口检查

| 检查项 | 结论 |
|---|---|
| 页面身份 | 只管理全部订单草稿，不承担新建、模板、正式订单或待办 |
| 列表结构 | 单列表；可继续优先，无法继续次级收纳 |
| 普通草稿退出 | 继续编辑或确认删除 |
| 撤回修改稿退出 | 继续修改或执行对应正式取消，不使用普通删除 |
| 正式身份与历史 | 订单／补充单编号及首次提交、撤回、重提或取消过程完整保留 |
| 入口与返回 | C00进入全部草稿；O01只恢复本单关联草稿；继续时回上次有效编辑位置 |
| 暂缓项 | 无；本页不依赖产品与器械组配细节即可成立 |
