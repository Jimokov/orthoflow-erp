## 1. 文件职责

本文件是手术通知 APP 页面设计的唯一进度总控，用来回答：

1. 当前正式页面有哪些；
2. 每一页服从什么规则；
3. 旧低保真还能否继续使用；
4. 当前应当重构、修订、回归还是暂缓；
5. 下一步只设计哪一组或哪一页；
6. 哪些内容属于相邻模块，不能在页面设计中擅自补写。

本文件不替代业务规则、页面清单、页面流程或单页结构说明。

## 4. 设计状态定义

| 状态 | 含义 |
|---|---|
| 外壳 | 只确认页面身份与入口，本阶段不展开内部内容 |
| 待设计 | 已确认需要该页，但没有当前有效页面结构 |
| 重构 | 页面身份保留，旧页面核心表达已与当前规则冲突 |
| 修订 | 旧页面主体可复用，需要调整入口、术语、信息层级或状态 |
| 回归验收 | 旧结构大体可用，但必须按当前规则逐项复核后才能继续 |
| 当前有效 | 页面结构和低保真均已按当前规则验收 |

旧项目中“已有低保真”只表示存在设计素材，不代表当前有效。
