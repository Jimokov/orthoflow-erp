## 4. 设计状态定义

| 状态 | 含义 |
|---|---|
| 外壳 | 只确认页面身份与入口，本阶段不展开内部内容 |
| 待设计 | 已确认需要该页，但没有当前有效页面结构 |
| 重构 | 页面身份保留，旧页面核心表达已与当前规则冲突 |
| 修订 | 旧页面主体可复用，需要调整入口、术语、信息层级或状态 |
| 回归验收 | 旧结构大体可用，但必须按当前规则逐项复核后才能继续 |
| 当前有效 | 页面结构和低保真均已按当前规则验收 |

旧项目中“已有低保真”只表示存在设计素材，不代表当前有效。

## 7. 当前推进顺序

### 第一批：O01与T系列

1. O01：先建立无任务、一项任务、多项任务三种结构状态；
2. T01：重构为订单协同时间线；
3. T02：对齐实际交付批次和多订单关联；
4. T03：作为T02内部异常分支回归；
5. T04：对齐手术植入衔接；
6. T05：对齐主动变更和T04延期／取消；
7. 完成O01—T入口、返回和同一任务去重验收。

### 第二批：O02—O04与S系列

对齐需求版本、履约交付、正式记录，以及待结余下的多种实物去向。

### 第三批：G与C系列回归

同步全局搜索、任务入口、手术通知工作区、模板退出和草稿来源，并完成G03外壳以外的结构讨论。

### 第四批：三级总览与整链路验收

按照“全部页面总览 → 组总览 → 单页详情”同步29页，检查入口、返回、表单恢复、空状态、错误状态和移动端适配。

页面结构验收完成后，才进入统一视觉稿或静态图；代码实现仍在其后。
